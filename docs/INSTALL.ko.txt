Sidepad 설치 및 사용 안내

필요 환경
- Windows 10/11, Intel 또는 AMD 64비트 PC. ARM/32비트 Windows는 미지원입니다.
- 설치 중 Windows 관리자 확인이 필요합니다.
- 기기는 최신 WebRTC 지원 브라우저를 사용합니다.

설치
1. Sidepad-Setup-0.2.0-x64.exe를 PC에 복사해 실행합니다.
2. 설치를 진행하고 드라이버 및 네트워크 설정을 위한 Windows 관리자 확인을 허용합니다.
3. 가상 드라이버 등록과 1920 × 1080 / 60 Hz 확장 설정이 자동 진행됩니다.
4. 재시작이 필요하다는 안내가 나오면 Windows를 재시작한 뒤 Sidepad를 실행합니다.
   남은 화면 설정은 자동으로 이어집니다. 재시작 전에는 설정 완료로 간주하지 않습니다.

앱과 서명된 드라이버가 EXE에 포함됩니다. Node.js, WinGet, 별도 드라이버 다운로드는 필요 없습니다.
기존 정상 드라이버는 재설치하지 않습니다. 가상 화면이 여러 개이거나 주 모니터이면 안내를 확인해 주세요.
설정이 실패하면 완료로 표시하지 않습니다. 설치 화면의 다시 시도 또는 앱의 '드라이버 설치 및 설정'을 사용하세요.

연결
1. PC와 기기를 같은 공유기에 연결합니다. PC는 유선 LAN도 가능합니다.
2. PC의 신뢰할 수 있는 홈/사무실 네트워크가 Windows의 '개인 네트워크'인지 확인합니다.
   설치 프로그램은 네트워크 프로필을 바꾸지 않으며, 방화벽은 Sidepad 실행 파일의 개인 네트워크/로컬 서브넷 연결만 허용합니다.
3. Sidepad의 QR을 기기에서 열고 연결하기를 누릅니다.
4. PC에서 가상 디스플레이를 선택하고 화면 전송 시작을 누릅니다.

제거
- Windows 설정 > 앱 > Sidepad에서 제거합니다.
- 제거 시 해당 설치 경로의 네트워크 규칙 정리를 위해 관리자 확인이 나올 수 있습니다.
- 다른 프로그램도 사용할 수 있는 가상 드라이버와 사용자 설정은 보존합니다.

배포 정보
- 이 버전의 Sidepad 앱/설치 EXE에는 배포자 코드서명이 없습니다. Windows가 게시자 확인 또는 SmartScreen 경고를 표시할 수 있습니다.
- 포함된 가상 드라이버의 기존 서명은 유지됩니다. Windows 인증서 저장소나 드라이버 보안 정책을 변경하지 않습니다.
- 함께 제공되는 .sha256 파일로 설치 파일의 SHA-256을 비교할 수 있습니다.
- 드라이버 라이선스와 고지는 설치 폴더의 resources/licenses 및 resources/THIRD_PARTY_NOTICES.md에 있습니다.
- 최초 설치가 없는 다른 PC에서의 실증은 별도로 필요합니다. 이 PC에서는 기존 드라이버를 사용하는 설치 흐름과 패키징된 앱을 검증했습니다.
